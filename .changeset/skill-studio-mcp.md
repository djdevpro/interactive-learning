The AI skill now makes the tutorial in Interactive Learning Studio when the studio is connected to the agent through its MCP server. The agent finds or creates the site in the library of the user, records the flow in the browser of the studio, writes the texts and markers, and publishes it to the project, while the user watches. The tutorial stays in the library, where the user comes back to it. Without the studio, the skill keeps the command line workflow.
